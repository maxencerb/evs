import { Tabs, TabItem } from '@astrojs/starlight/components';

Reads `balanceOf` for every token in a runtime `address[]` and returns the balances as one
array, in one `eth_call`. Use it where you would reach for a multicall.

## Program

<Tabs syncKey="example">
  <TabItem label="script.ts">
    ```ts title="script.ts" {7-9, 15}
    import { evscript, t } from '@maxencerb/evs';
    import { erc20Abi } from 'viem';

    export const balances = evscript(
      { name: 'balances', args: [t.array(t.address), t.address] },
      (s, tokens, owner) => {
        const out = s.newArray(t.uint256, tokens.length());
        s.forEach(tokens, (token, i) => {
          const balance = s.tryRead({
            address: token,
            abi: erc20Abi,
            functionName: 'balanceOf',
            args: [owner],
          });
          out.set(i, balance.value); // 0n when the call fails
        });
        return s.return({ balances: out });
      },
    );
    ```
  </TabItem>
  <TabItem label="client.ts">
    ```ts title="client.ts" {16}
    import { createPublicClient, http } from 'viem';
    import { mainnet } from 'viem/chains';
    import { balances } from './script';

    const client = createPublicClient({ chain: mainnet, transport: http() });

    const tokens = [
      '0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48', // USDC
      '0xC02aaA39b223FE8D0A0e5C4F27eAD9083C756Cc2', // WETH
      '0x000000000000000000000000000000000000dEaD', // not a token: reports 0n
    ] as const;

    const result = await client.readContract({
      ...balances.compile().toViem(),
      functionName: 'balances',
      args: [tokens, '0xd8dA6BF26964aF9D7eEd9e03E53415D37aA96045'],
    });
    ```
  </TabItem>
</Tabs>

## Result

One balance per token, in input order:

```ts
declare const result: {
  balances: readonly bigint[];
};
```

## What to notice

- **The list is an argument.** [`evscript`](/reference/evscript/) declares `tokens` with
  [`t.array`](/reference/types/array/) and the client passes it in `args`, so one compiled script
  serves 3 tokens or 300.
- **The loop runs on-chain.** [`s.forEach`](/reference/builder/for-each/) iterates at run time,
  over whatever [`length`](/reference/expr/bytes-and-arrays/#length) the caller sends.
- **Results collect in an array.** [`s.newArray`](/reference/builder/new-array/) allocates a
  zero-filled `uint256[]`, [`out.set`](/reference/builder/new-array/#mutarray) fills it, and
  [`s.return`](/reference/builder/return/) takes it as is.
- **A bad token costs one slot.** [`s.tryRead`](/reference/builder/try-read/) never reverts and
  its `value` is zero when the call fails, so the other balances still come back.
- **A hostile token can burn the gas.** `s.tryRead` forwards all the gas by default: cap each
  call with [`gas`](/reference/builder/try-read/#gas-optional).

:::caution[Deployless stops at 765 balances]
The default mode caps the encoded result at 24,576 bytes, which is 765 balances here: one more
and the node rejects the call. Split the list, or use
[`toViem({ mode: 'stateOverride' })`](/reference/artifact/to-viem/), which has no cap. See
[deployless limits](/guides/execution/#deployless-limits).
:::
