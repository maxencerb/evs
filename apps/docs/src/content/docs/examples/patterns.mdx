Small recipes for common needs. Each example is complete: copy it as is.

## Default on failure

[`s.tryRead`](/reference/builder/try-read/) never reverts, and
[`s.select`](/reference/builder/select/) swaps in a default when the call fails or does not
decode.

```ts {5-6}
import { evscript, t } from '@maxencerb/evs';
import { erc20Abi } from 'viem';

const decimalsOf = evscript({ name: 'decimalsOf', args: [t.address] }, (s, token) => {
  const d = s.tryRead({ address: token, abi: erc20Abi, functionName: 'decimals' });
  return s.return({ decimals: s.select(d.success, d.value, 18) });
});
```

## Legacy bytes32 symbol

A few early tokens, MKR among them, return `symbol()` as a `bytes32`: read that form when the
`string` read fails, and convert it with [`asString`](/reference/expr/conversions/#asstring).

```ts {7-14}
import { evscript, t } from '@maxencerb/evs';
import { erc20Abi, erc20Abi_bytes32 } from 'viem';

const tokenSymbol = evscript({ name: 'tokenSymbol', args: [t.address] }, (s, token) => {
  const text = s.tryRead({ address: token, abi: erc20Abi, functionName: 'symbol' });
  const symbol = s.let(t.string, text.value);
  s.if(text.success.not(), () => {
    const raw = s.tryRead({
      address: token,
      abi: erc20Abi_bytes32,
      functionName: 'symbol',
    });
    symbol.set(raw.value.asString()); // 'MKR' and 29 zero bytes become 'MKR'
  });
  return s.return({ symbol: symbol.get() });
});
```

## Stop at the first match

A value set inside [`s.forEach`](/reference/builder/for-each/) leaves the loop through a
[cell](/reference/builder/let/#cell), and [`loop.break()`](/reference/builder/while/#loopctl)
skips the remaining iterations.

```ts {7, 16-17}
import { evscript, t } from '@maxencerb/evs';
import { erc20Abi, zeroAddress } from 'viem';

const firstHeld = evscript(
  { name: 'firstHeld', args: [t.array(t.address), t.address] },
  (s, tokens, owner) => {
    const found = s.let(t.address, zeroAddress);
    s.forEach(tokens, (token, _i, loop) => {
      const balance = s.read({
        address: token,
        abi: erc20Abi,
        functionName: 'balanceOf',
        args: [owner],
      });
      s.if(balance.gt(0n), () => {
        found.set(token);
        loop.break();
      });
    });
    return s.return({ token: found.get() });
  },
);
```

## Reuse a subroutine

[`s.fn`](/reference/builder/fn/) compiles its body once however often you call it, and takes
everything it needs as parameters: the body cannot use outer values.

```ts {7-9}
import { evscript, t } from '@maxencerb/evs';
import { erc20Abi } from 'viem';

const pairBalances = evscript(
  { name: 'pairBalances', args: [t.address, t.address, t.address] },
  (s, tokenA, tokenB, owner) => {
    const balanceOf = s.fn('balanceOf', [t.address, t.address], (token, who) =>
      s.read({ address: token, abi: erc20Abi, functionName: 'balanceOf', args: [who] }),
    );
    return s.return({ a: balanceOf(tokenA, owner), b: balanceOf(tokenB, owner) });
  },
);
```

## Guard a division

A [`div`](/reference/expr/arithmetic/#div) by zero reverts with `Panic(0x12)`: divide inside
[`s.if`](/reference/builder/if/) and carry the result out in a
[cell](/reference/builder/let/#cell).

```ts {18-21}
import { evscript, t } from '@maxencerb/evs';
import { erc20Abi } from 'viem';

const shareBps = evscript(
  { name: 'shareBps', args: [t.address, t.address] },
  (s, token, owner) => {
    const supply = s.read({
      address: token,
      abi: erc20Abi,
      functionName: 'totalSupply',
    });
    const balance = s.read({
      address: token,
      abi: erc20Abi,
      functionName: 'balanceOf',
      args: [owner],
    });
    const bps = s.let(t.uint256, 0n);
    s.if(supply.gt(0n), () => {
      bps.set(balance.mul(10_000n).div(supply));
    });
    return s.return({ bps: bps.get() });
  },
);
```

## Read a past block

A script is a plain `eth_call`, so `blockNumber` pins every read in it to one block.

```ts {16}
import { evscript, t } from '@maxencerb/evs';
import { createPublicClient, erc20Abi, http } from 'viem';
import { mainnet } from 'viem/chains';

const supplyOf = evscript({ name: 'supplyOf', args: [t.address] }, (s, token) => {
  const supply = s.read({ address: token, abi: erc20Abi, functionName: 'totalSupply' });
  return s.return({ supply });
});

const client = createPublicClient({ chain: mainnet, transport: http() });

const { supply } = await client.readContract({
  ...supplyOf.compile().toViem(),
  functionName: 'supplyOf',
  args: ['0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48'], // USDC
  blockNumber: 22_000_000n,
});
```

:::caution[Blocks before Cancun]
The default bytecode targets the Cancun fork (mainnet block 19,426,587) and fails on older
blocks. Pass [`evmVersion`](/reference/compile/#evmversion-optional) to `compile()`: see
[EVM targets](/guides/evm-targets/).
:::
