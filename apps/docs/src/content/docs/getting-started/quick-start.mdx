title: Quick start
description: Describe a contract, write a script and run it with viem as one typed eth_call.
---

Read a Uniswap V3 pool's two tokens, then each token's symbol, in one `eth_call`. You need
[`@maxencerb/evs` and `viem`](/getting-started/installation/).

## 1. Describe the contracts

viem ships `erc20Abi`, so only the pool needs an ABI.

```ts title="abi.ts"
import { parseAbi } from 'viem';

export const poolAbi = parseAbi([
  'function token0() view returns (address)',
  'function token1() view returns (address)',
]);
```

An ABI written as an object literal works too, as long as it ends with `as const`.

## 2. Write the script

[`evscript`](/reference/evscript/) runs your callback once and records the reads, so `token0`
is a placeholder for an address that exists only inside the call.

```ts title="script.ts" {10-11}
import { evscript, t } from '@maxencerb/evs';
import { erc20Abi } from 'viem';
import { poolAbi } from './abi';

export const poolTokens = evscript(
  { name: 'poolTokens', args: [t.address] },
  (s, pool) => {
    const token0 = s.read({ address: pool, abi: poolAbi, functionName: 'token0' });
    const token1 = s.read({ address: pool, abi: poolAbi, functionName: 'token1' });
    const symbol0 = s.read({ address: token0, abi: erc20Abi, functionName: 'symbol' });
    const symbol1 = s.read({ address: token1, abi: erc20Abi, functionName: 'symbol' });
    return s.return({ token0, token1, symbol0, symbol1 });
  },
);
```

## 3. Compile and run

[`compile`](/reference/compile/) produces the bytecode, and
[`toViem()`](/reference/artifact/to-viem/) returns the `abi` and `code` that `readContract`
needs.

```ts title="client.ts" {10}
import { compile } from '@maxencerb/evs';
import { createPublicClient, http } from 'viem';
import { mainnet } from 'viem/chains';
import { poolTokens } from './script';

const client = createPublicClient({ chain: mainnet, transport: http() });
const compiled = compile(poolTokens);

const result = await client.readContract({
  ...compiled.toViem(),
  functionName: 'poolTokens',
  args: ['0x88e6A0c2dDD26FEEb64F039a2c41296FcB3f5640'], // USDC/WETH 0.05% pool
});
```

viem sends one `eth_call` that carries the bytecode. Nothing is deployed and no transaction is
sent.

## Result

viem infers `args` and the result from the script. Each key of
[`s.return`](/reference/builder/return/) becomes a field.

```ts
type Result = {
  token0: `0x${string}`; // USDC
  token1: `0x${string}`; // WETH
  symbol0: string; // 'USDC'
  symbol1: string; // 'WETH'
};
```
