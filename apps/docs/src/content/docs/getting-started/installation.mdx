Install `@maxencerb/evs` together with `viem`, its one required peer dependency.

<Tabs syncKey="pm">
  <TabItem label="npm">

    ```sh
    npm install @maxencerb/evs viem
    ```
  </TabItem>
  <TabItem label="pnpm">
    ```sh
    pnpm add @maxencerb/evs viem
    ```
  </TabItem>
  <TabItem label="bun">
    ```sh
    bun add @maxencerb/evs viem
    ```
  </TabItem>
  <TabItem label="yarn">

    ```sh
    yarn add @maxencerb/evs viem
    ```
  </TabItem>

## Requirements

| Requirement | Version | Notes |
| --- | --- | --- |
| `viem` | `>=2.14.1` | Required peer dependency. |
| TypeScript | `>=5.5` | Optional peer dependency. Set `"strict": true`. |
| Node.js | `>=20.19` | Bun works too. |
| Module format | ESM | No CommonJS build: use `import`, from one of the two [entry points](#entry-points). |

## Verify the setup

```ts
import { compile, evscript, t } from '@maxencerb/evs';

const double = evscript({ name: 'double', args: [t.uint256] }, (s, x) => {
  return s.return({ doubled: x.mul(2n) });
});

const { runtimeBytecode } = compile(double); // 0x…
```

This compiles without a network. If it typechecks and runs, continue with the
[quick start](/getting-started/quick-start/).

## Entry points

| Import from | Holds | Use it |
| --- | --- | --- |
| `@maxencerb/evs` | everything: the builder, the compiler, the utilities | to write, compile and test scripts |
| `@maxencerb/evs/runtime` | `hydrate`, the error decoders, the deployless helpers and the error classes, without the compiler | in a client that runs [precompiled scripts](/reference/precompiled/) |

```ts
import { compile, evscript, t } from '@maxencerb/evs';
import { decodeScriptError, hydrate } from '@maxencerb/evs/runtime';
```

The optional [Vite plugin](/reference/vite-plugin/), `@maxencerb/vite-plugin-evs`, compiles
your scripts during the build, so the client bundle holds the second entry only: see
[Precompiling scripts](/guides/precompiling/).

## Custom abitype types

evs has no dependencies of its own: its ABI types are viem's. An abitype
[`Register`](https://abitype.dev/config) augmentation in your project, such as a custom
`addressType`, applies to evs and viem alike.

With pnpm, add `abitype` to your project at the version your viem pins, so the augmentation
targets viem's copy.
