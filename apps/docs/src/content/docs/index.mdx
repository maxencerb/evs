## From ABI to typed result in three steps

The example reads a Uniswap V3 pool's two tokens and each token's symbol: four reads, two of
which target addresses that only exist once the first two have returned. One `eth_call` runs all
of them.

<Steps>

1. **Describe the contracts.** Plain `as const` ABI fragments, the same shape viem uses. viem
   already ships `erc20Abi`, so only the pool needs writing down.

   ```ts title="abis.ts"
   export const poolAbi = [
     { type: 'function', name: 'token0', stateMutability: 'view', inputs: [], outputs: [{ type: 'address' }] },
     { type: 'function', name: 'token1', stateMutability: 'view', inputs: [], outputs: [{ type: 'address' }] },
   ] as const;
   ```

2. **Write the script.** The callback runs once, at build time, and records what the bytecode
   will do. Every value it touches is an `Expr`, a typed placeholder for something that only
   exists inside the `eth_call`. Passing one call's result as the next call's address is the
   part a multicall cannot express.

   ```ts title="script.ts" collapse={3-7}
   import { evscript, t } from '@maxencerb/evs';
   import { erc20Abi } from 'viem';
   // abis.ts (step 1)
   const poolAbi = [
     { type: 'function', name: 'token0', stateMutability: 'view', inputs: [], outputs: [{ type: 'address' }] },
     { type: 'function', name: 'token1', stateMutability: 'view', inputs: [], outputs: [{ type: 'address' }] },
   ] as const;

   export const poolTokens = evscript({ name: 'poolTokens', args: [t.address] }, (s, pool) => {
     const token0 = s.read({ address: pool, abi: poolAbi, functionName: 'token0' });
     //    ^? Expr<'address'>
     const token1 = s.read({ address: pool, abi: poolAbi, functionName: 'token1' });
     // The target of these two calls is the result of the previous two.
     const symbol0 = s.read({ address: token0, abi: erc20Abi, functionName: 'symbol' });
     const symbol1 = s.read({ address: token1, abi: erc20Abi, functionName: 'symbol' });
     return s.return({ token0, token1, symbol0, symbol1 });
   });
   ```

3. **Compile it and run it with viem.** `compile` produces verified runtime bytecode plus a
   literal-typed ABI. `toViem()` hands both to `readContract` as a deployless `eth_call`, and
   the argument list and the result object are inferred from the script.

   ```ts title="main.ts" collapse={4-19}
   import { compile } from '@maxencerb/evs';
   import { createPublicClient, http } from 'viem';
   import { mainnet } from 'viem/chains';
   // script.ts (step 2)
   import { evscript, t } from '@maxencerb/evs';
   import { erc20Abi } from 'viem';
   const poolAbi = [
     { type: 'function', name: 'token0', stateMutability: 'view', inputs: [], outputs: [{ type: 'address' }] },
     { type: 'function', name: 'token1', stateMutability: 'view', inputs: [], outputs: [{ type: 'address' }] },
   ] as const;
   const poolTokens = evscript({ name: 'poolTokens', args: [t.address] }, (s, pool) => {
     const token0 = s.read({ address: pool, abi: poolAbi, functionName: 'token0' });
     const token1 = s.read({ address: pool, abi: poolAbi, functionName: 'token1' });
     const symbol0 = s.read({ address: token0, abi: erc20Abi, functionName: 'symbol' });
     const symbol1 = s.read({ address: token1, abi: erc20Abi, functionName: 'symbol' });
     return s.return({ token0, token1, symbol0, symbol1 });
   });

   const compiled = compile(poolTokens);

   const client = createPublicClient({ chain: mainnet, transport: http() });
   const out = await client.readContract({
     ...compiled.toViem(), // { abi, code }: a plain deployless eth_call
     functionName: 'poolTokens',
     args: ['0x88e6A0c2dDD26FEEb64F039a2c41296FcB3f5640'], // typed readonly [pool: `0x${string}`]
   });
   // out: { token0: `0x${string}`; token1: `0x${string}`; symbol0: string; symbol1: string }
   ```

</Steps>
