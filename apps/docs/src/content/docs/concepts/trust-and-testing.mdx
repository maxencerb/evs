---
title: Why trust the bytecode?
description: Every compile verifies its own output, and the test suite pins the bytecode against an interpreter, viem's codecs and solc.
---

A compiler bug does not throw: it returns wrong data from a call that looks successful. evs
guards against that twice, with checks inside every `compile()` and with tests against
independent references.

## Checks on every compile

[`compile`](/reference/compile/) runs all of these on every call, with or without `optimize`.

| Check | What it guarantees |
| --- | --- |
| IR validation | The [recorded program](/concepts/how-it-works/) has consistent types and scopes, before and after dead code is removed. |
| Size limit | The runtime bytecode fits 24,576 bytes (EIP-170). |
| `JUMPDEST` scan | Every jump lands on a real `JUMPDEST`, never in push data or a data segment. |
| Stack simulation | No underflow, one known height at every label, a depth of 16 at most. |
| Fork lint | No opcode newer than the chosen [`evmVersion`](/guides/evm-targets/). |
| Forbidden opcodes | No storage, transient storage, log, `CREATE`, `CREATE2`, `CALLCODE`, `DELEGATECALL` or `SELFDESTRUCT` opcode. |
| Returndata lint | Every `RETURNDATACOPY` copies the whole returndata, so it cannot read out of bounds. |

A failed check throws, so you never receive unverified bytecode. The size limit throws
`EvsCompileError` (`COMPILE_LIMIT`). A failed bytecode check throws `EvsInternalError`
(`INTERNAL`): a bug in evs to report.

## What the tests compare against

The test suite compares the compiled bytecode with independent references.

| Reference | What must match |
| --- | --- |
| [`interpret`](/reference/utilities/interpret/), which runs the recorded program in TypeScript | Returndata and revert payloads, byte for byte, for the default and the `optimize: true` output. |
| viem's ABI codecs | The encoded result, the decoded arguments and the calldata of every call, byte for byte. |
| solc 0.8.30 reference contracts | Arithmetic results and `Panic` payloads on boundary values. |
| Hostile callees | Malformed returndata reverts with `EvsDecodeError`, or returns `success = false` from a `try*` verb. Never an out-of-gas halt. |
| A real node (anvil) | The same decoded result in deployless mode, in state-override mode and as deployed code. |

CI runs these suites on every pull request. `interpret` is exported, so your own tests can use
the same reference: see [Testing scripts](/guides/testing-scripts/).
