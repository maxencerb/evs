---
title: EVM targets
description: Choose the EVM fork a script is compiled for with evmVersion, so it runs on older chains and at historical blocks.
---

`compile()` builds for one EVM fork, `cancun` by default. A chain or a historical block that
lacks that fork's opcodes needs an older target.

## Setting the target

```ts {9}
import { compile, evscript, t } from '@maxencerb/evs';
import { erc20Abi } from 'viem';

const symbolOf = evscript({ name: 'symbolOf', args: [t.address] }, (s, token) => {
  const symbol = s.read({ address: token, abi: erc20Abi, functionName: 'symbol' });
  return s.return({ symbol });
});

const compiled = compile(symbolOf, { evmVersion: 'paris' });
compiled.options.evmVersion; // 'paris'
```

`evmVersion` is `'paris'`, `'shanghai'` or `'cancun'`, exported as the `EvmVersion` type. Any
other value throws `EvsCompileError` (`EVM_VERSION`).

## What each target changes

```ts {9-10, 14-16}
import { compile, evscript, t, type EvmVersion } from '@maxencerb/evs';
import { erc20Abi } from 'viem';

const symbolOf = evscript({ name: 'symbolOf', args: [t.address] }, (s, token) => {
  const symbol = s.read({ address: token, abi: erc20Abi, functionName: 'symbol' });
  return s.return({ symbol });
});

function forkOpcodes(evmVersion: EvmVersion) {
  const lines = compile(symbolOf, { evmVersion }).disassemble().lines;
  return ['PUSH0', 'MCOPY'].filter((op) => lines.some((line) => line.mnemonic === op));
}

forkOpcodes('cancun'); // ['PUSH0', 'MCOPY']
forkOpcodes('shanghai'); // ['PUSH0']
forkOpcodes('paris'); // []
```

The script returns the same result on every target. Only two instructions change:

| Target | Pushing zero | Copying memory | Runs from |
| --- | --- | --- | --- |
| `cancun` (default) | `PUSH0` | `MCOPY` | Cancun |
| `shanghai` | `PUSH0` | a copy loop | Shanghai |
| `paris` | `PUSH1 0x00` | a copy loop | Constantinople |

- **Istanbul for two reads.** With `paris`, a script that reads `s.env('chainid')` or its own
  balance needs Istanbul.
- **One artifact per target.** Bytecode differs between targets, and an older target is
  slightly larger.

## Which target to use

| Where the call runs | Target |
| --- | --- |
| A chain on Cancun or later, such as Ethereum mainnet today | `cancun` |
| A chain with Shanghai but not Cancun | `shanghai` |
| A chain without Shanghai, or one you are unsure about | `paris` |
| Mainnet, block 19,426,587 or later | `cancun` |
| Mainnet, blocks 17,034,870 to 19,426,586 | `shanghai` |
| Mainnet, blocks 7,280,000 to 17,034,869 | `paris` |
| Mainnet, before block 7,280,000 | none: no evs script runs there |

Other chains activated these forks at their own block heights. On mainnet, Istanbul starts at
block 9,069,000.

## Historical blocks

The target must match the fork active at the block you read, not the chain's current fork.

```ts {10-11, 17, 20}
import { compile, evscript, t, type EvmVersion } from '@maxencerb/evs';
import { createPublicClient, erc20Abi, http } from 'viem';
import { mainnet } from 'viem/chains';

const supplyOf = evscript({ name: 'supplyOf', args: [t.address] }, (s, token) => {
  const supply = s.read({ address: token, abi: erc20Abi, functionName: 'totalSupply' });
  return s.return({ supply });
});

const targetAt = (block: bigint): EvmVersion =>
  block >= 19_426_587n ? 'cancun' : block >= 17_034_870n ? 'shanghai' : 'paris';

const client = createPublicClient({ chain: mainnet, transport: http() });

function supplyAt(blockNumber: bigint) {
  return client.readContract({
    ...compile(supplyOf, { evmVersion: targetAt(blockNumber) }).toViem(),
    functionName: 'supplyOf',
    args: ['0xC02aaA39b223FE8D0A0e5C4F27eAD9083C756Cc2'],
    blockNumber,
  });
}
```

## Spotting a wrong target

A target that is too new fails at run time, with no hint of the cause in the default mode:

| Mode | What you see |
| --- | --- |
| Deployless | a bare `execution reverted`, with no revert data |
| State override | the node's invalid-opcode error (`NotActivated` on anvil) |

`explainRevert` on the empty payload names the opcodes to suspect:

```ts {9}
import { compile, evscript, t } from '@maxencerb/evs';
import { erc20Abi } from 'viem';

const symbolOf = evscript({ name: 'symbolOf', args: [t.address] }, (s, token) => {
  const symbol = s.read({ address: token, abi: erc20Abi, functionName: 'symbol' });
  return s.return({ symbol });
});

compile(symbolOf).explainRevert('0x').message;
// '… the runtime uses MCOPY (cancun) and PUSH0 (shanghai) (evmVersion 'cancun'); for
//  a block or chain before that fork, recompile with an older evmVersion ('paris' runs
//  everywhere)'
```
