Test a script's logic in milliseconds with `interpret()` and a mock chain. Run the compiled
bytecode against a local anvil node when the test depends on a real chain.

## Which one to use

| | `interpret()` | anvil |
| --- | --- | --- |
| Needs | a mock chain you write | foundry's `anvil` |
| Runs | the script's recorded program, in TypeScript | the compiled bytecode, in a node |
| Speed | synchronous, milliseconds | one RPC round trip per call |
| Best for | logic, branches, edge cases, reverts | real contracts, both execution modes, gas and size limits |

`interpret()` returns the same bytes as the bytecode, for results and for reverts: see
[why trust the bytecode?](/concepts/trust-and-testing/) It does not model gas, the script's
balance, or state that changes between calls.

## Without a node

```ts {16-22, 24}
import { evscript, interpret, t, type MockChain } from '@maxencerb/evs';
import { encodeFunctionResult, erc20Abi } from 'viem';

const decimalsOf = evscript({ name: 'decimalsOf', args: [t.address] }, (s, token) => {
  const d = s.tryRead({ address: token, abi: erc20Abi, functionName: 'decimals' });
  return s.return({ decimals: s.select(d.success, d.value, 18) });
});

const USDC = '0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48';
const six = encodeFunctionResult({
  abi: erc20Abi,
  functionName: 'decimals',
  result: 6,
});

const chain: MockChain = {
  // USDC answers 6, every other address reverts
  staticcall: ({ to }) =>
    to === USDC.toLowerCase()
      ? { success: true, data: six }
      : { success: false, data: '0x' },
};

const { outcome } = interpret(decimalsOf, [USDC], chain);
// outcome → { kind: 'return', data: '0x…06', values: { decimals: 6 } }
```

The mock answers each call the script makes with `{ success, data }`. `args` and
`outcome.values` are typed like `readContract`'s arguments and result.

- `staticcall` answers `s.read` and `s.tryRead`. It is the only required method.
- `call` answers `s.call` and `s.simulate`, and `account` answers `s.balance`, `s.codeSize`
  and `s.codeHash`. Both are optional: see [`interpret`](/reference/utilities/interpret/).
- `interpret()` is synchronous and needs no setup, so it runs in any test runner.

:::caution[Addresses arrive in lowercase]
`to` is always lowercase. Comparing it with a checksummed address never matches, so the mock
takes its fallback branch without an error. Compare with `address.toLowerCase()`.
:::

## Testing a revert

```ts {8-11}
import { compile, evscript, interpret, t, type MockChain } from '@maxencerb/evs';

const ratio = evscript({ name: 'ratio', args: [t.uint256, t.uint256] }, (s, x, y) =>
  s.return({ q: x.div(y) }),
);
const noCalls: MockChain = { staticcall: () => ({ success: false, data: '0x' }) };

const { outcome } = interpret(ratio, [1n, 0n], noCalls);
// outcome → { kind: 'revert', data: '0x4e487b71…12' }
const why = compile(ratio).explainRevert(outcome.data);
// why.kind → 'panic', why.panicCode → 18n (0x12, division by zero)
```

A revert is an outcome, not an exception: `outcome.data` is the exact payload the bytecode
reverts with. To test a failing contract, answer `success: false` from the mock.

## Unused results do not revert

```ts {4, 9, 11-12}
import { evscript, interpret, t, type MockChain } from '@maxencerb/evs';

const check = evscript({ name: 'check', args: [t.uint256, t.uint256] }, (s, a, b) => {
  a.sub(b); // nothing reads the result: the subtraction and its check are dropped
  return s.return({ a });
});
const noCalls: MockChain = { staticcall: () => ({ success: false, data: '0x' }) };

interpret(check, [1n, 2n], noCalls).outcome.kind; // 'return', like the bytecode

const asRecorded = interpret(check, [1n, 2n], noCalls, { dce: false });
asRecorded.outcome.kind; // 'revert': Panic(0x11)
```

The compiler removes a checked operation whose result nothing reads, and `interpret()` does
the same unless you pass [`dce: false`](/reference/utilities/interpret/#dce-optional). To make
a check count, use its result, or write it with [`s.if`](/reference/builder/if/) and
[`s.throw`](/reference/builder/throw/).

## Setting the environment

```ts {8-13}
import { evscript, interpret, type MockChain } from '@maxencerb/evs';

const stamp = evscript({ name: 'stamp' }, (s) =>
  s.return({ at: s.env('timestamp'), by: s.env('caller') }),
);
const noCalls: MockChain = { staticcall: () => ({ success: false, data: '0x' }) };

const { outcome } = interpret(stamp, [], noCalls, {
  env: {
    timestamp: 1_750_000_000n,
    caller: '0xd8dA6BF26964aF9D7eEd9e03E53415D37aA96045',
  },
});
// outcome.values → { at: 1750000000n, by: '0xd8dA…6045' }
```

[`env`](/reference/utilities/interpret/#env-optional) sets what
[`s.env`](/reference/builder/env/) returns: `address`, `caller`, `timestamp`, `blocknumber`
and `chainid`. Use it to test a script as each
[execution mode](/guides/execution/#choosing-a-mode) would run it.

## Against a local node

Start a node that forks mainnet at a fixed block, so results never change:

```sh
anvil --fork-url $MAINNET_RPC_URL --fork-block-number 22000000
```

```ts {13}
import { compile, evscript, t } from '@maxencerb/evs';
import { createPublicClient, erc20Abi, http } from 'viem';

const tokenInfo = evscript({ name: 'tokenInfo', args: [t.address] }, (s, token) => {
  const symbol = s.read({ address: token, abi: erc20Abi, functionName: 'symbol' });
  const decimals = s.read({ address: token, abi: erc20Abi, functionName: 'decimals' });
  return s.return({ symbol, decimals });
});
const compiled = compile(tokenInfo);

const client = createPublicClient({ transport: http('http://127.0.0.1:8545') });

for (const params of [compiled.toViem(), compiled.toViem({ mode: 'stateOverride' })]) {
  const info = await client.readContract({
    ...params,
    functionName: 'tokenInfo',
    args: ['0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48'],
  });
  // info → { symbol: 'USDC', decimals: 6 }, in both modes
}
```

This is the same `readContract` call as in production, so it covers what `interpret()` cannot:
the RPC, the [execution mode](/guides/execution/) and real contract code. anvil supports both
modes.
