A JS `if` or `for` runs once, [while the script is built](/guides/writing-scripts/), so it cannot
depend on a chain value. The `s.*` combinators record branches and loops that run on-chain.

## Branching with s.if

[`s.if`](/reference/builder/if/) runs a block only when its condition holds. Results leave the
block through a [cell](/reference/builder/let/#cell).

```ts {5-7}
import { evscript, t } from '@maxencerb/evs';

const ratio = evscript({ name: 'ratio', args: [t.uint256, t.uint256] }, (s, a, b) => {
  const bps = s.let(t.uint256, 0n);
  s.if(b.gt(0n), () => {
    bps.set(a.mul(10_000n).div(b)); // skipped when b is 0
  });
  return s.return({ bps: bps.get() });
});
```

- A third callback is the `else` branch.
- An `Expr` created inside a branch cannot be used after it. Store it in a cell.

:::caution[Branch callbacks run at build time]
Both callbacks of `s.if` run once while the script is built, whatever the condition. A JS
assignment inside one (`fee = 5n`) always happens. Write to a cell with `set` instead.
:::

## Picking a value with s.select

[`s.select`](/reference/builder/select/) is a ternary over two values that already exist.

```ts {4}
import { evscript, t } from '@maxencerb/evs';

const clamp = evscript({ name: 'clamp', args: [t.uint256, t.uint256] }, (s, x, max) => {
  const clamped = s.select(x.gt(max), max, x);
  return s.return({ clamped });
});
```

Both sides are computed first, so it cannot skip a call or a division by zero. Use `s.if` for
that.

## Looping over an array

The batch pattern: allocate the output with `s.newArray`, write one result per element, return
the array.

<LoopCollect />

```ts {8-16}
import { evscript, t } from '@maxencerb/evs';
import { erc20Abi } from 'viem';

const balances = evscript(
  { name: 'balances', args: [t.array(t.address), t.address] },
  (s, tokens, owner) => {
    const out = s.newArray(t.uint256, tokens.length());
    s.for({ from: 0n, until: tokens.length() }, (i) => {
      const balance = s.read({
        address: tokens.at(i),
        abi: erc20Abi,
        functionName: 'balanceOf',
        args: [owner],
      });
      out.set(i, balance);
    });
    return s.return({ balances: out });
  },
);
```

`s.forEach` is the same loop with the element handed to you:

```ts {6-8}
import { evscript, t } from '@maxencerb/evs';
import { erc20Abi } from 'viem';

const totals = evscript({ name: 'totals', args: [t.array(t.address)] }, (s, tokens) => {
  const out = s.newArray(t.uint256, tokens.length());
  s.forEach(tokens, (token, i) => {
    out.set(i, s.read({ address: token, abi: erc20Abi, functionName: 'totalSupply' }));
  });
  return s.return({ totals: out });
});
```

| Loop | Use it to | The body receives |
| --- | --- | --- |
| [`s.for`](/reference/builder/for/) | count from `from` up to `until` | `(i, loop)` |
| [`s.forEach`](/reference/builder/for-each/) | walk an array | `(elem, i, loop)` |
| [`s.while`](/reference/builder/while/) | repeat while a condition holds | `(loop)` |

## Looping on a condition

`s.while` takes its condition as a callback, evaluated before every iteration.

```ts {6}
import { evscript, t } from '@maxencerb/evs';

const log2 = evscript({ name: 'log2', args: [t.uint256] }, (s, x) => {
  const rest = s.let(x);
  const bits = s.let(t.uint256, 0n);
  s.while(() => rest.get().gt(1n), () => {
    rest.set(rest.get().shr(1n));
    bits.set(bits.get().add(1n));
  });
  return s.return({ bits: bits.get() });
});
```

:::caution[Read cells inside the condition]
A snapshot taken before the loop never changes. `s.while(() => done, …)` with `done` computed
outside either never runs or runs until the call is out of gas.
:::

## Leaving a loop early

Every loop body receives a [`LoopCtl`](/reference/builder/while/#loopctl) as its last parameter.

```ts {10}
import { evscript, t } from '@maxencerb/evs';

const indexOf = evscript(
  { name: 'indexOf', args: [t.array(t.address), t.address] },
  (s, xs, x) => {
    const index = s.let(xs.length()); // the length means "not found"
    s.forEach(xs, (elem, i, loop) => {
      s.if(elem.eq(x), () => {
        index.set(i);
        loop.break();
      });
    });
    return s.return({ index: index.get() });
  },
);
```

- `loop.break()` leaves the loop.
- `loop.continue()` starts the next iteration. In `s.for` and `s.forEach` the counter still
  advances.

## Reusing code with s.fn

[`s.fn`](/reference/builder/fn/) declares a function inside the script. Its body is compiled
once, however many times you call it.

```ts {5-7}
import { evscript, t } from '@maxencerb/evs';
import { erc20Abi } from 'viem';

const pair = evscript({ name: 'pair', args: [t.address, t.address] }, (s, a, b) => {
  const symbolOf = s.fn('symbolOf', [t.address], (token) =>
    s.read({ address: token, abi: erc20Abi, functionName: 'symbol' }),
  );
  return s.return({ symbolA: symbolOf(a), symbolB: symbolOf(b) });
});
```

- The body cannot use handles of the enclosing script: pass them as parameters.
- A plain JS helper that calls `s.*` also works. It is inlined at every call.
