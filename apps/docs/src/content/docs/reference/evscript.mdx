Defines a script. Your callback runs once to record it, and you get back an `EvsScript` with a
typed ABI, ready to [compile](/reference/compile/).

## Import

```ts
import { evscript } from '@maxencerb/evs';
```

## Usage

```ts
import { evscript, t } from '@maxencerb/evs';
import { erc20Abi } from 'viem';

const balanceOf = evscript(
  { name: 'balanceOf', args: [t.address, t.address] },
  (s, token, holder) => {
    const balance = s.read({
      address: token,
      abi: erc20Abi,
      functionName: 'balanceOf',
      args: [holder],
    });
    return s.return({ balance });
  },
);
```

The first argument defines the script. The second builds it: `s` is the
[builder](/reference/builder/), followed by one handle per entry of `args`.

### No arguments

Leave `args` out.

```ts
import { evscript } from '@maxencerb/evs';

const blockNow = evscript({ name: 'blockNow' }, (s) =>
  s.return({ timestamp: s.env('timestamp'), height: s.env('blocknumber') }),
);
```

### Named arguments

[`namedArg`](/reference/types/named-arg/) names an argument in the ABI, so viem labels it. A bare
type is named `arg0`, `arg1`, and so on.

```ts {7}
import { evscript, namedArg, t } from '@maxencerb/evs';
import { erc20Abi, type ReadContractParameters } from 'viem';

const balanceOf = evscript(
  {
    name: 'balanceOf',
    args: [namedArg('token', t.address), namedArg('holder', t.address)],
  },
  (s, token, holder) => {
    const balance = s.read({
      address: token,
      abi: erc20Abi,
      functionName: 'balanceOf',
      args: [holder],
    });
    return s.return({ balance });
  },
);

type Args = ReadContractParameters<typeof balanceOf.abi, 'balanceOf'>['args'];
// readonly [token: `0x${string}`, holder: `0x${string}`]
```

### Struct arguments

A struct or tuple argument arrives as a [`Tuple`](/reference/builder/tuple/#tuple) handle. Read a
field with `.get()`.

```ts {11-12}
import { evscript, t } from '@maxencerb/evs';

const MarketParams = t.struct({
  loanToken: t.address,
  collateralToken: t.address,
  lltv: t.uint256,
});

const market = evscript({ name: 'market', args: [MarketParams] }, (s, params) =>
  s.return({
    loanToken: params.loanToken.get(), // Expr<'address'>
    lltv: params.lltv.get(), // Expr<'uint256'>
  }),
);
```

### Declared errors

Create an error with [`t.error`](/reference/types/error/), list it in `errors`, and throw it with
[`s.throw`](/reference/builder/throw/).

```ts {6,9}
import { evscript, namedArg, t } from '@maxencerb/evs';

const TooSmall = t.error('TooSmall', [namedArg('amount', t.uint256)]);

const guard = evscript(
  { name: 'guard', args: [t.uint256], errors: [TooSmall] },
  (s, amount) => {
    s.if(amount.lt(10n), () => {
      s.throw(TooSmall, { amount });
    });
    return s.return({ doubled: amount.mul(2n) });
  },
);
```

Declared errors join the script ABI, so viem decodes them by name.

## Returns

`EvsScript`

The recorded script. It is frozen, and its ABI is typed before you compile anything.

| Member | Type | Description |
| --- | --- | --- |
| `name` | `string` | The script name, kept as a literal type. |
| `abi` | `ScriptAbi` | One `view` function, the two evs runtime errors, then your declared errors. Same value as [the artifact's `abi`](/reference/artifact/#properties). |
| `errors` | `readonly EvsErrorType[]` | The declared errors, in order. Empty when there are none. |
| `ir` | `ScriptIr` | The recorded program, as plain JSON data. Run it with [`interpret`](/reference/utilities/interpret/) or store it with [`serializeIr`](/reference/utilities/serialize-ir/). |
| `compile(options?)` | `CompiledEvsScript` | Shorthand for [`compile(script, options)`](/reference/compile/). |

```ts
import { evscript, t } from '@maxencerb/evs';
import { encodeFunctionData } from 'viem';

const double = evscript({ name: 'double', args: [t.uint256] }, (s, x) =>
  s.return({ doubled: x.mul(2n) }),
);

double.name; // 'double'
double.errors; // []
const data = encodeFunctionData({
  abi: double.abi,
  functionName: 'double',
  args: [21n],
});
const compiled = double.compile(); // same as compile(double)
```

## Parameters

### name

- **Type:** `string`

The script name. It becomes the name of the ABI function, so it is the `functionName` you pass to
viem. Use letters, digits and `_`, not starting with a digit.

```ts {5}
import { evscript, t } from '@maxencerb/evs';

const double = evscript(
  {
    name: 'double',
    args: [t.uint256],
  },
  (s, x) => s.return({ doubled: x.mul(2n) }),
);
```

### args (optional)

- **Type:** `ArgInput | readonly ArgInput[]`
- **Default:** `[]`

The script arguments, in order. Each entry is a type from [`t`](/reference/types/), a
[`namedArg`](/reference/types/named-arg/), or a parameter object taken from an ABI. A single entry
needs no array.

```ts {6}
import { evscript, t } from '@maxencerb/evs';

const double = evscript(
  {
    name: 'double',
    args: t.uint256, // same as [t.uint256]
  },
  (s, x) => s.return({ doubled: x.mul(2n) }),
);
```

### errors (optional)

- **Type:** `EvsErrorType | readonly EvsErrorType[]`
- **Default:** `[]`

The custom errors the script can throw, each created with [`t.error`](/reference/types/error/).
[`s.throw`](/reference/builder/throw/) accepts only these. A single error needs no array.

```ts {9}
import { evscript, t } from '@maxencerb/evs';

const Empty = t.error('Empty');

const first = evscript(
  {
    name: 'first',
    args: [t.array(t.uint256)],
    errors: [Empty],
  },
  (s, values) => {
    s.if(values.length().eq(0n), () => {
      s.throw(Empty);
    });
    return s.return({ first: values.at(0n) });
  },
);
```

### body

- **Type:** `(s, ...args) => ScriptReturn`

The callback that builds the script. It receives the [builder](/reference/builder/) `s`, then one
handle per entry of `args`. It must return the value of [`s.return`](/reference/builder/return/).

```ts {5-8}
import { evscript, t } from '@maxencerb/evs';

const average = evscript(
  { name: 'average', args: [t.uint256, t.uint256] },
  (s, a, b) => {
    const sum = a.add(b); // a and b are Expr<'uint256'>
    return s.return({ average: sum.div(2n) });
  },
);
```

| Declared type | Handle the body receives |
| --- | --- |
| a word type, `string`, `bytes`, any array | an [`Expr`](/reference/expr/) of that type |
| `t.struct(...)`, `t.tuple(...)` | a [`Tuple`](/reference/builder/tuple/#tuple) |

## Behavior

- **Runs once.** The body runs when you call `evscript`, not on chain. Plain JavaScript in it
  runs at build time: see [writing scripts](/guides/writing-scripts/).
- **Positional arguments.** The order of `args` is the order of the body parameters and of the
  viem `args` array. Names only label them.
- **Errors at your line.** A builder error is thrown from inside the body, so the stack trace
  points at the line that caused it.
- **No `as const`.** `args` and `errors` keep their literal types when written inline.
- **Frozen result.** The script and its `ir` cannot be modified.

## Errors

Thrown by `evscript` itself. Errors from builder calls are listed on each builder page and in
[error codes](/reference/diagnostics/#error-codes).

| Error | When |
| --- | --- |
| `EvsTypeError` (`TYPE_MISMATCH`) | `name` is not an identifier, or is `__proto__` |
| `EvsTypeError` (`TYPE_MISMATCH`) | an `args` entry is not a supported type |
| `EvsTypeError` (`UNSUPPORTED_V0`) | an array type nests more than four levels deep, or a type has a static size of 2^32 bytes or more |
| `EvsTypeError` (`ABI_SHAPE`) | two arguments share a name, or a name is not an identifier |
| `EvsTypeError` (`ERROR_DECL`) | an `errors` entry was not made by `t.error`, or two share a name or selector |
| `EvsTypeError` (`ERROR_DECL`) | `name` is also the name of a declared error, or of `EvsDecodeError` or `EvsInvalidCalldata` |
| `EvsTypeError` (`TYPE_MISMATCH`) | the body does not return the value of `s.return` |
