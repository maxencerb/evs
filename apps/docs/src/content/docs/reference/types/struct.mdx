Builds a struct type with named members. The script reads members by name and viem decodes the
value to an object.

## Usage

```ts {3}
import { evscript, t } from '@maxencerb/evs';

const Position = t.struct({ owner: t.address, liquidity: t.uint128 });

const check = evscript({ name: 'check', args: [Position] }, (s, position) => {
  const liquidity = position.liquidity.get(); // Expr<'uint128'>
  return s.return({ owner: position.owner.get(), funded: liquidity.gt(0n) });
});
```

A struct argument arrives as a [`Tuple`](/reference/builder/tuple/#tuple) handle, not an `Expr`.
It has one field per member, read with `.get()`.

### Calling the script

From viem, a struct argument is an object keyed by member name.

```ts {15}
import { evscript, t } from '@maxencerb/evs';
import { createPublicClient, http } from 'viem';
import { mainnet } from 'viem/chains';

const Position = t.struct({ owner: t.address, liquidity: t.uint128 });

const check = evscript({ name: 'check', args: [Position] }, (s, position) =>
  s.return({ funded: position.liquidity.get().gt(0n) }),
);

const client = createPublicClient({ chain: mainnet, transport: http() });
const { funded } = await client.readContract({
  ...check.compile().toViem(),
  functionName: 'check',
  args: [{ owner: '0xd8dA6BF26964aF9D7eEd9e03E53415D37aA96045', liquidity: 1000n }],
});
```

### Nested members

A member can be any type: another struct, an array, a `string`.

```ts {3-4}
import { evscript, t } from '@maxencerb/evs';

const Token = t.struct({ token: t.address, symbol: t.string });
const Pool = t.struct({ token0: Token, token1: Token, fees: t.array(t.uint24) });

const inspect = evscript({ name: 'inspect', args: [Pool] }, (s, pool) => {
  const symbol = pool.token0.get().symbol.get(); // Expr<'string'>
  const fees = pool.fees.get(); // Expr<'uint24[]'>
  return s.return({ symbol, tiers: fees.length() });
});
```

### Building and returning a struct

[`s.tuple`](/reference/builder/tuple/) allocates a struct value. A `Tuple` handle is returned as
is, and viem decodes it to an object.

```ts {6-7}
import { evscript, t } from '@maxencerb/evs';

const Position = t.struct({ owner: t.address, liquidity: t.uint128 });

const open = evscript({ name: 'open', args: [t.address] }, (s, owner) => {
  const position = s.tuple(Position, { owner, liquidity: 1000n });
  return s.return({ position });
});
// result: { position: { owner: `0x${string}`; liquidity: bigint } }
```

## Returns

`TupleType`

A frozen descriptor with one named component per member, in the order you wrote them.

```ts
import { t } from '@maxencerb/evs';

const Position = t.struct({ owner: t.address, liquidity: t.uint128 });
// {
//   type: 'tuple',
//   components: [
//     { name: 'owner', type: 'address' },
//     { name: 'liquidity', type: 'uint128' },
//   ],
// }
```

## Parameters

### spec

- **Type:** `Record<string, EvsType>`

One entry per member: the key is the member name, the value is its type.

```ts {4-5}
import { t } from '@maxencerb/evs';

const Market = t.struct({
  loanToken: t.address,
  lltv: t.uint256,
});
```

## Behavior

- **Order matters.** Members are ABI-encoded in key order. To mirror a Solidity struct, keep its
  member order: another order is another type, with another encoding and hash.
- **Names are identifiers.** A member name matches `/^[A-Za-z_]\w*$/` and is not `__proto__`.
- **Structural.** Two structs with the same member names and types, in the same order, are the
  same type.
- **Handle names win.** A member named like a member of the
  [`Tuple`](/reference/builder/tuple/#tuple) handle, such as `at`, `expr`, `then` or `toString`,
  has no named field. Read it by position with `.at(i)`.
- **From an ABI.** [`t.fromOutputs`](/reference/types/from-outputs/) derives a struct from an ABI
  instead of retyping it.

## Errors

Thrown by the `t.struct` call, except the last row:

| Error | When |
| --- | --- |
| `EvsTypeError` (`TYPE_MISMATCH`) | `spec` is not a plain object, or has no member |
| `EvsTypeError` (`TYPE_MISMATCH`) | a member name is not an identifier, or is `__proto__` |
| `EvsTypeError` (`TYPE_MISMATCH`) | a member value is not a type |
| `EvsTypeError` (`UNSUPPORTED_V0`) | a member nests arrays more than four levels deep |
| `EvsTypeError` (`UNSUPPORTED_V0`) | the ABI static size is 2^32 bytes or more |
| `EvsCompileError` (`UNSUPPORTED_V0`) | at `compile()`: structs and arrays nest too deeply to decode, flatten the type |
