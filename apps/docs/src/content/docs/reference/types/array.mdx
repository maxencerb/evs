Builds an array type, dynamic (`T[]`) or fixed-size (`T[N]`), over any element type. The element
can be a primitive, a struct, a tuple or another array.

## Usage

```ts {3}
import { evscript, t } from '@maxencerb/evs';

const sum = evscript({ name: 'sum', args: [t.array(t.uint256)] }, (s, amounts) => {
  const total = s.let(t.uint256, 0n);
  s.forEach(amounts, (amount) => {
    total.set(total.get().add(amount));
  });
  return s.return({ total: total.get() });
});
```

`amounts` is an `Expr<'uint256[]'>`. Read it with
[`length`](/reference/expr/bytes-and-arrays/#length) and
[`at`](/reference/expr/bytes-and-arrays/#at), or loop over it with
[`s.forEach`](/reference/builder/for-each/).

### Fixed size

Pass a length to get a `T[N]`. It reads like a dynamic array.

```ts {3}
import { evscript, t } from '@maxencerb/evs';

const spread = evscript({ name: 'spread', args: [t.array(t.int24, 2)] }, (s, ticks) => {
  // ticks: Expr<'int24[2]'>
  return s.return({ width: ticks.at(1n).sub(ticks.at(0n)) });
});
```

### Arrays of structs

The element can be a [`t.struct`](/reference/types/struct/) or a
[`t.tuple`](/reference/types/tuple/). Each element is then a
[`Tuple`](/reference/builder/tuple/#tuple) handle.

```ts {5}
import { evscript, t } from '@maxencerb/evs';

const Position = t.struct({ owner: t.address, liquidity: t.uint128 });

const owner = evscript({ name: 'owner', args: [t.array(Position)] }, (s, positions) => {
  const first = positions.at(0n); // a Tuple handle
  return s.return({ owner: first.owner.get(), count: positions.length() });
});
```

### Nested arrays

Arrays nest up to four levels. Each `at` peels one level.

```ts {3}
import { evscript, t } from '@maxencerb/evs';

const Grid = t.array(t.array(t.uint256)); // 'uint256[][]'

const corner = evscript({ name: 'corner', args: [Grid] }, (s, rows) => {
  const row = rows.at(0n); // Expr<'uint256[]'>
  return s.return({ corner: row.at(0n), rows: rows.length() });
});
```

### Array literals

From viem, an array argument is a plain JS array. A fixed-size array is a tuple of exactly `N`
elements, and an array of structs is an array of objects.

```ts {16-20}
import { evscript, t } from '@maxencerb/evs';
import { createPublicClient, http } from 'viem';
import { mainnet } from 'viem/chains';

const Position = t.struct({ owner: t.address, liquidity: t.uint128 });

const count = evscript(
  { name: 'count', args: [t.array(t.uint256), t.array(t.int24, 2), t.array(Position)] },
  (s, amounts, ticks, positions) => s.return({ n: positions.length() }),
);

const client = createPublicClient({ chain: mainnet, transport: http() });
const { n } = await client.readContract({
  ...count.compile().toViem(),
  functionName: 'count',
  args: [
    [1n, 2n, 3n], // uint256[]
    [-10, 10], // int24[2]
    [{ owner: '0xd8dA6BF26964aF9D7eEd9e03E53415D37aA96045', liquidity: 1000n }],
  ],
});
```

Inside a script, an array literal is also a JS array, and its elements can be `Expr` values.

```ts {4-5}
import { evscript, t } from '@maxencerb/evs';

const fees = evscript({ name: 'fees', args: [t.uint24] }, (s, custom) => {
  const tiers = s.lit(t.array(t.uint24), [100, 500, 3000, custom]);
  const bounds = s.lit(t.array(t.int24, 2), [-887272, 887272]); // exactly two elements
  return s.return({ tiers, bounds });
});
```

## Returns

`ArrayType | TupleType`

A type string, such as `'uint256[]'`. When the element is a struct or a tuple, a descriptor
tagged `tuple[]` or `tuple[N]`.

```ts
import { t } from '@maxencerb/evs';

t.array(t.uint256); // 'uint256[]'
t.array(t.uint256, 2); // 'uint256[2]'
t.array(t.array(t.string), 3); // 'string[][3]'
t.array(t.struct({ id: t.uint256 }));
// { type: 'tuple[]', components: [{ name: 'id', type: 'uint256' }] }
```

## Parameters

### elem

- **Type:** `EvsType`

The element type: a primitive, a struct or tuple, or another array.

```ts {4}
import { t } from '@maxencerb/evs';

const names = t.array(
  t.string,
);
```

### length (optional)

- **Type:** `number`
- **Default:** none, the array is dynamic

The fixed length `N` of a `T[N]`: an integer from 1 to 2^32 − 1.

```ts {5}
import { t } from '@maxencerb/evs';

const pair = t.array(
  t.address,
  2,
);
```

## Behavior

- **Same string.** `t.array(t.uint256)` is the string `'uint256[]'`. Writing the string yourself
  gives the same type.
- **Four levels.** `uint256[][][][]` is the deepest array. One more level throws.
- **Literal length.** Inside a script, TypeScript does not count the elements of a `T[N]`
  literal. A wrong count throws `TYPE_MISMATCH` when the script is built.
- **Size cap.** A type whose ABI static size reaches 2^32 bytes is rejected, such as
  `t.array(t.uint256, 2 ** 27)`.

## Errors

Thrown by the `t.array` call:

| Error | When |
| --- | --- |
| `EvsTypeError` (`TYPE_MISMATCH`) | `elem` is not a type |
| `EvsTypeError` (`TYPE_MISMATCH`) | `length` is not an integer from 1 to 2^32 − 1 |
| `EvsTypeError` (`UNSUPPORTED_V0`) | the array nests more than four levels deep |
| `EvsTypeError` (`UNSUPPORTED_V0`) | the ABI static size is 2^32 bytes or more |
