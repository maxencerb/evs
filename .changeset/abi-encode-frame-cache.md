Cheaper and smaller ABI encoding, with the same bytes on the wire. The encoder behind returns, `s.encode` and call/simulate calldata now loads an array element's pointer and a struct element's base once per iteration, instead of re-deriving them for every member. Returning 30 eight-field structs with a string member costs about 35% less gas (73.6k to 48.2k for the whole echo) and the script is 27% smaller. Structs nested three or more dynamic levels deep keep each level's base in memory, so encoding one more level costs the same at any depth instead of growing with it (encoding an eight-level struct costs 40% less). Every return also loses a stack shuffle, and the selector of a call with struct or composite-array arguments, and the `s.simulate` trampoline selector, take 8 bytes instead of 33. Calls whose arguments nest dynamic structs three or more levels deep now reserve a few words of encoder memory below their calldata, as calls with fixed-size or composite-array arguments already did. Because that reservation advances the free pointer, the `LOOP_ALLOCATION` warning now flags all such calls inside a loop, including reads whose outputs are all words.
